# Design System - Gestion Stock & Ventes

## Design Philosophy

### Color Palette
- **Primary**: Deep Forest Green (#1B4332) - Trust, stability, growth
- **Secondary**: Warm Amber (#F77F00) - Energy, success, alerts
- **Accent**: Sage Green (#52796F) - Balance, nature, calm
- **Neutral**: Charcoal (#2D3748) - Professional, readable text
- **Background**: Off-white (#FAFAFA) - Clean, spacious
- **Success**: Emerald (#10B981) - Positive actions, stock alerts
- **Warning**: Orange (#F59E0B) - Low stock, attention needed

### Typography
- **Display Font**: Canela (serif) - Strong, editorial headlines
- **Body Font**: Suisse Int'l (sans-serif) - Clean, readable content
- **Monospace**: JetBrains Mono - Numbers, codes, prices

### Visual Language
- Clean, professional interface with generous white space
- Subtle shadows and rounded corners for modern feel
- Card-based layout for information hierarchy
- Consistent iconography using Feather icons
- Data visualization with harmonious color schemes

## Visual Effects & Animations

### Used Libraries
- **Anime.js**: Smooth micro-interactions and form animations
- **ECharts.js**: Interactive charts and data visualization
- **Splide.js**: Product carousels and image galleries
- **p5.js**: Dynamic background patterns and visual elements
- **Matter.js**: Physics-based animations for dashboard elements

### Animation Effects
- **Text Effects**: 
  - Color cycling emphasis for important metrics
  - Split-by-letter stagger for headings
  - Gradient text animation for CTAs
- **Background**: 
  - Subtle particle system using p5.js
  - Organic shape morphing in hero areas
- **Interactions**:
  - Smooth hover states with scale and shadow
  - Loading states with progress indicators
  - Form validation with gentle shake animations

### Styling Approach
- **Mobile-First**: Responsive design starting from 320px
- **Grid System**: CSS Grid for main layout, Flexbox for components
- **Component-Based**: Reusable UI elements with consistent styling
- **Accessibility**: High contrast ratios, focus states, screen reader support

### Header Effects
- Dynamic background with subtle geometric patterns
- Animated company logo on page load
- Smooth transitions between dashboard sections
- Floating action buttons with physics-based movement

### Data Visualization Style
- Harmonious color palette with maximum 4 colors per chart
- Clean, minimal chart designs with clear labels
- Interactive tooltips with smooth transitions
- Responsive charts that adapt to screen size
- Subtle animations on data updates
